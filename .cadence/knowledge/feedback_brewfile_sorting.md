Always sort Brewfile entries alphabetically within each category: Binaries (Brew Formulae), GUI Applications (Casks), and App Store Apps.

**Why:** User preference for consistent, scannable ordering.

**How to apply:** When adding or removing entries from the Brewfile, maintain alphabetical sort order within each section.
